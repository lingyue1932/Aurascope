本模块按职责拆为四个并列文件，无内部子包：
- `styles.py` 是样式根，定义 `_C` token 字典（中性色、主色、语义色、字阶、间距、圆角）并生成 `STYLESHEET`、`DIALOG_STYLESHEET`、`POPUP_QSS` 三个字符串常量；所有颜色/字号必须从该字典取用，禁止散写。
- `ui_components.py` 暴露 `create_*` 工厂函数（按钮、标签、滑块、分组框、分割线等），每个控件通过 `setObjectName` 绑定到 styles 中的 QSS 选择器；同时提供 `CollapsibleSection`、`attach_empty_button`、`attach_empty_hint`、`enable_click_sort`、`style_combo_popups`、`copy_bgr_to_clipboard` 等跨页面复用的行为增强。
- `ui_dialogs.py` 封装 `show_toast`（底部轻提示，基于 `QTimer.singleShot` 自动销毁）和 `show_message`（info/warning/error 三态，错误级附带「打开日志」按钮，调用 `app_paths.log_dir()`）。
- `help_dialogs.py` 提供 `MarkdownDialog`（读取 `resource_path` 下的 Markdown 文档）与 `AboutDialog`（版本、构建日期、数据/日志目录、MIT 许可），依赖 `app_version.APP_VERSION`、`recipe.recipe_dir` 等外部模块。
依赖方向单向向外：help_dialogs → ui_components + app_paths/app_version/recipe；ui_dialogs → app_paths；ui_components/styles 不反向依赖业务模块。
