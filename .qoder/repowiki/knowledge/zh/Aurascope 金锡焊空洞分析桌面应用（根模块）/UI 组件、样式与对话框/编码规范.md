- 所有可复用控件通过 `create_xxx` 工厂函数返回，工厂只负责实例化与设置 objectName，布局由调用方完成。
- 控件通过 `setObjectName`（如 PrimaryBtn、SecondaryBtn、InfoLabel、CardTitle、Divider、CollapseBody 等）与 `styles.py` 中同名 QSS 选择器一一对应，避免在业务代码中手写样式。
- 破坏性操作使用 `confirm_action`，并在 `QT_QPA_PLATFORM=offscreen` 或 `AURASCOPE_AUTO_CONFIRM=1` 时静默返回 True，以便 CI 自动化测试不阻塞。
- 用户反馈统一走 `ui_dialogs.show_toast` / `show_info/show_warning/show_error`，不在业务逻辑里直接弹出 QMessageBox。
- 对话框类（MarkdownDialog、AboutDialog）继承 QDialog，使用 QVBoxLayout 组织，并通过 `create_primary_button` / `create_secondary_button` 构造关闭/辅助按钮。
- 样式值全部取自 `styles._C` 字典，禁止在 QSS 或 Python 中硬编码十六进制颜色，以保证品牌色与灰阶的一致性。
