- GUI 测试统一在模块顶部设置 `os.environ.setdefault('QT_QPA_PLATFORM', 'offscreen')` 后创建 `QApplication`，并通过 `app.processEvents()` 或 `QTest.qWait` 让异步 UI 刷新完成。
- 需要写配方的测试将配方目录隔离到 `.workbuddy/tmp_recipes`，并通过 `AURASCOPE_RECIPE_DIR` 环境变量注入，避免污染用户桌面配方库。
- 面向用户的断言脚本采用自定义 `chk(name, cond, extra='')` 累加 `PASS`/`FAIL` 计数并打印 `[OK]`/`[FAIL]` 行，最后返回 0/1 作为进程退出码。
- Qt 交互通过 `QTest.mouseClick` / `mousePress` / `mouseMove` / `keyClick` 配合 `self.point(x,y)` 坐标转换来驱动画布，而不是直接调用内部方法。
- 对耗时检测调用使用 `patch('area_tab.detect_defects', wraps=image.detect_defects)` 包装真实实现，以同时统计调用次数并保留行为。
- UI 走查类脚本（`test_ui_audit.py`、`test_quick_teach.py`、`test_quick_teach_flow.py`）在结束时把截图保存到 `.workbuddy/validation/` 下，文件名体现被测组件。
