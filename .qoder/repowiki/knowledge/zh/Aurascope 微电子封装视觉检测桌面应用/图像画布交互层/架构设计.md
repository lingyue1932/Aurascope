模块由一个通用基类与四个业务画布组成，依赖方向单向：业务画布 → ui_components.paint_empty_state / app_paths.resource_path，不反向依赖上层 Tab。
- canvas.py 的 ImageCanvas 是共享基元：实现 widget↔image 坐标转换、fit_in_view、鼠标滚轮缩放（以光标为锚点）、右键拖拽平移、ROI 多边形/矩形编辑（含顶点吸附 edge_snap_mask、按 scale 自适应 hit_radius）、局部 Otsu 笔刷（preview/placed/confirmed 三态）以及空洞删除悬停高亮；通过 calib_drawn / roi_poly_finished / roi_rect_finished / void_* 等 pyqtSignal 把交互结果上抛给 Tab 层。
- area_canvas.py 的 AreaCanvas 在基元之上叠加缺陷对象渲染：mask_to_qimage 把 numpy mask 转 QImage，mask_hit/hit_index 做像素级命中检测，distance_entries 支持带水平/竖直约束（7° snap）的距离标注。
- counting_canvas.py 的 CountingCanvas 是最简画布，仅负责 ROI 框选、对象轮廓填充与 hover 高亮，并通过 object_add_at/object_delete_at 信号与算法层联动。
- measure_canvas.py 的 MeasureCanvas 专注标定线 + 距离测量，内置 _snap_endpoint 与 MODE_COLORS，完成测量后发射 measurement_added 并显示 μm 单位标签。
- stitching_canvas.py 的 StitchingCanvas 独立维护 images[] 列表与 current_image_idx，支持标记点对齐、X/Y 双轴偏移计算、线性羽化融合（_feather_weight）与可选互相关微调（STITCH_AUTO_REFINE=False），stitch_images 通过 progress_callback 回调进度。
所有画布统一遵循「set_image → fit_in_view → paintEvent」生命周期，空状态复用 paint_empty_state，避免各自重复绘制空白提示。
