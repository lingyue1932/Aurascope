- 控件工厂函数（create_primary_button / create_secondary_button / create_success_button / create_danger_button / create_nav_button / create_info_label / create_card_title 等）只负责实例化并 setObjectName，不持有父容器也不参与布局。
- 所有颜色、字号、圆角、间距均从 styles._C 读取并通过 QSS 选择器应用，业务代码中不出现裸色值或硬编码尺寸。
- 需要弹出层的控件（QComboBox）通过 ui_components.style_combo_popups 将 POPUP_QSS 单独应用到 view()，而非依赖全局 stylesheet。
- 破坏性操作统一走 ui_components.confirm_action，并在 offscreen 环境或 AURASCOPE_AUTO_CONFIRM=1 时自动放行，保证非交互场景可用。
- 用户反馈统一走 ui_dialogs.show_toast 与 show_message/info/warning/error，错误级别额外记录到 'Aurascope' logger 并提供「打开日志」入口。
- 对话框与帮助窗口通过 help_dialogs.MarkdownDialog / AboutDialog 复用 create_card_title/subtitle/divider/button 等工厂，保持与主界面一致的视觉语言。
