模块按「启动 → 资源定位 → 日志 → UI」单向依赖组织：
- `main.py` 是 Qt 应用唯一入口，顺序执行：初始化日志 → 安装全局异常钩子 → 配置 HighDPI/Fusion 主题 → 创建 QApplication 并设置图标/样式表 → 实例化 `MainWindow` → 显式绑定销毁信号触发 `app.quit()` → 延迟关闭 PyInstaller 启动图。
- `app_paths.py` 提供 `resource_path` / `app_dir` / `local_data_dir` / `log_dir` / `build_date`，通过 `sys.frozen` 与 `sys._MEIPASS` 区分源码运行与 PyInstaller onefile 打包两种路径语义，所有外部资源与数据均经此层访问。
- `logging_setup.py` 在 `~\AppData\Local\Aurascope\logs\aurascope.log` 下使用 `RotatingFileHandler`（1MB×5）写入滚动日志，并通过 `sys.excepthook` + `threading.excepthook` 兜住主线程与子线程未捕获异常，同时提供带复制/打开日志按钮的统一错误对话框；该对话框内部再 try/except 自身以避免二次崩溃。
- `update_check.py` 以 `UpdateChecker(QObject)` 形式封装对 `https://api.github.com/repos/lingyue1932/Aurascope/releases/latest` 的异步请求，返回结构为 `{version, tag, url, notes}`，仅当 release 非 draft/prerelease 且版本号严格大于当前 `APP_VERSION` 时才发射 `update_found` 信号；网络失败或 JSON 解析失败一律静默降级，仅在 `manual=True` 时通过 `check_finished` 回调上报错误。
- `app_version.py` 集中声明 `APP_VERSION = '6.3.0'`，作为窗口标题与更新检查的唯一来源，避免硬编码分散。
