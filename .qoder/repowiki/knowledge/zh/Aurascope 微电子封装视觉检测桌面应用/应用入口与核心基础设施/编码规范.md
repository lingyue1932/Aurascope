- 路径与资源访问统一走 `app_paths.py` 暴露的函数，禁止在业务代码中直接拼接 `sys.executable` 或 `__file__`。
- 所有对外部资源的读取都通过 `getattr(sys, 'frozen', False)` / `sys._MEIPASS` 分支处理，保证源码与打包产物行为一致。
- 日志输出统一使用命名 logger `Aurascope`，而非 root logger，便于后续过滤与隔离。
- 可选/外部依赖（如 `pyi_splash`、PyQt GUI 组件）采用运行时 import + try/except ImportError 的惰性加载方式，避免在无 GUI 环境下导入失败。
