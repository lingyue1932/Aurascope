模块由三层组成：
- 数据层 `recipe.py`：纯 Python（不依赖 Qt），负责配方 JSON 的读写、校验与版本迁移。通过 `_recipe_root()` 在 frozen 模式下优先使用 exe 同级 `recipes/`，不可写时回退到 `app_paths.local_data_dir()`；支持环境变量 `AURASCOPE_RECIPE_DIR` 覆盖存储目录。配方分两类——v1 参数型（`.json`）与 v2/v3 示教模型（`.taught.json`，`type='taught'`），后者字段含 `solder/background/void/band/scale_bar/diagnostics` 等，并通过 `validate_taught` 将旧 schema < 3 的面积上下限统一迁移为自动档。
- UI 交互层 `quick_teach_dialog.py`：`QuickTeachDialog` 实现「① 焊层区域 → ② 点选空洞」两步向导，复用 `canvas.ImageCanvas` 做 ROI 多边形绘制、顶点拖拽与空洞点选，调用 `image.locate_solder_band / grab_local_dark_blob / learn_taught_model / apply_taught_model` 实时学习并预览结果；可选比例尺标定通过 `calib_drawn` 回调计算 `px_per_um` 并提取条棒模板图。
- 报告层 `learn_dialog.py`：`LearnReportDialog` + `build_learn_items` 把模型字典翻译为带状态标记（ok/warn/info）的明细卡片，供完整示教流程展示。
依赖方向单向：UI 层 → `image` 算法 + `recipe` 持久化；`recipe` 不反向依赖任何 UI。
