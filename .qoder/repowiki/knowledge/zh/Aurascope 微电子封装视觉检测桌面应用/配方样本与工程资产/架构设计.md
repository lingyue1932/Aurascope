本模块不承载运行时逻辑，是 Aurascope 的静态资产层，由三类文件组成：
- `recipes/*.taught.json`：已标定示教配方数据，遵循 schema_version=3 的 JSON 结构，包含 solder/background/void/band/band_ref/scale_bar/diagnostics 等字段，对应空洞分析流程中“样板图 → 点选空洞 → 焊层区域 → 比例尺 → 学习”产出的参数快照。
- `AurascopeV6.spec` + `version_info.txt`：PyInstaller 打包入口，指定 onedir 输出 `AurascopeV6.3` 目录（禁用 UPX、排除 pandas/matplotlib/PySide2）、Splash 启动图 `splash_boot.png`、图标 `logo_1.ico`，并通过 `version='version_info.txt'` 注入 Windows 文件属性（VSVersionInfo，版本号 6.3.0，Company=Innolight）。
- `README.md` + `说明书.md`：对外文档，前者给出源码运行与打包命令，后者按 ROI/空洞/示教批量/剪切力/计数/拼接顺序说明操作流程、快捷键与日志路径。
依赖方向单向向外：应用代码通过 app_paths.py 读取 recipes 目录；本模块不反向 import 任何 Python 包。
