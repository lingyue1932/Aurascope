三个独立的 unittest.TestCase 文件，按被测模块边界切分：
- test_area_tab.py：前半段（DetectDefectsTests）直接 import image 并对 detect_defects 做纯 NumPy 单元测试，断言对象 schema（id/area_px/cx/cy/rect/points/mask）、连通性、ROI 裁剪、八连通、质心、min_area、输入不变性与只读切片支持；后半段（AreaFormattingTests + AreaUITests）通过 QApplication 实例化 area_tab.DefectAreaTab，使用 QTest.mouseClick/QTest.qWait 驱动 ROI 绘制、Otsu、标定、距离测量、批量检测队列、CSV 导出等端到端场景。
- test_teach_batch_logic.py：仅验证 teach_batch_tab.TeachBatchTab 在 AURASCOPE_RECIPE_DIR 临时目录下的快速示教入口合并、quick_model 别名、QuickTeachDialog 可选标定与配方选择逻辑。
- test_update_check.py：纯函数测试 update_check.parse_release_tag / release_is_newer / should_show_update / parse_latest_release，依赖 packaging.version.Version 做语义版本比较。
依赖方向单向：tests → image / area_tab / teach_batch_tab / update_check，不反向被业务代码引用。
