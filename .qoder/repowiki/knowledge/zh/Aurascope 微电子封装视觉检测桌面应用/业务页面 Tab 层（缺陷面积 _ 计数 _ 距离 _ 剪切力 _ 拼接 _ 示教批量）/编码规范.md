- 侧栏统一用 `QFrame(SidebarCard)` + `QScrollArea` + `QVBoxLayout` 包裹，最小宽度 280–420，内容区 margin 16/spacing 14。
- 按钮通过 `ui_components` 的 `create_primary_button` / `create_secondary_button` / `create_danger_button` 工厂创建，而非直接实例化 QPushButton。
- 长耗时操作（阈值滑动、批量检测）通过 `QTimer.singleShot(150)` 或 `QTimer(0)` 队列化，避免拖拽时重复计算。
- CSV 导出统一使用 `csv_export.write_csv` 或 Python `csv.writer` + `tempfile.NamedTemporaryFile` + `os.replace` 原子写入。
- 用户确认危险操作（清空 ROI/清空图像/停止检测）一律经 `confirm_action` 弹窗二次确认。
- 状态更新集中到 `_refresh_results` / `_sync_canvas` / `_update_stats` 等单一刷新方法，由多个动作入口复用，避免分散写表。
