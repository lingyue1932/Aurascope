每个文件对应一个顶层 `QWidget` 子 Tab，统一采用「左侧滚动侧栏 + 右侧画布」布局：侧栏负责参数输入与结果表格，右侧通过 `AreaCanvas` / `CountingCanvas` / `MeasureCanvas` / `StitchingCanvas` / `ImageCanvas` 渲染交互；Tab 本身不实现像素级算法，而是调用 `image.py` 中的 `detect_defects` / `detect_objects` / `locate_solder_band` / `apply_taught_model` 等函数。

- area_tab.py：多 ROI 缺陷面积测量，维护 ROI 列表（mask/params/status）、手动增删对象、标定线、距离测量与 Otsu 自动阈值；通过 `_run_roi` + `_run_next_batch` 串行执行检测，用 `QTimer(150ms)` 防抖滑块拖动。
- counting_tab.py：单图物体计数，支持形态学去噪（核大小/形状）与分水岭分离粘连物，CSV 字段含编号/面积/中心/宽高。
- measure_tab.py：纯交互式距离测量，先划线标定再逐次测距，统计 min/max/mean/total，导出 CSV。
- shear_tab.py：无画布，纯 MIL-STD-883H Method 2019.9 芯片剪切力计算器，按 mm²→in² 换算并输出 1X/1.25X/2X 的 g/N 值，带面积越界警告。
- stitching_tab.py：多图水平线对齐拼接，支持文件夹导入、逐张标记金锡线、进度条拼接、PNG/TIF 保存及剪贴板复制，并通过 `main_window.set_stitching_result` 反向推送空洞分析页。
- teach_batch_tab.py：体量最大，拆分为「示教学习」和「批量检测」两个模式；核心是 `BatchWorker(QThread)` 顺序处理批次、发射 `progress/tile_done/finished/failed` 信号，结果只传轻量键（剥离 `band_mask`/`voids`），缩略图按需重算；提供快速示教两步流程、配方 JSON 读写（`recipe.py`）、比例尺模板识别、单图核对修正（编辑焊层多边形/增删空洞）以及汇总大图/金锡拼接条导出。

依赖方向单向向下：Tab → canvas.* + image.py + csv_export + ui_components/ui_dialogs；teach_batch_tab 额外依赖 recipe.py 与 main_window 的回调接口。
