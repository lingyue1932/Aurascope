- Qt 控件一律通过 ui_components.py 的 create_* 工厂函数创建，不在业务 Tab 中直接 new 控件并自行设置尺寸策略。
- 全局样式通过 styles.py 的 QSS token 管理，颜色与字号命名采用统一的 design token 风格，HiDPI 适配集中在样式层。
- 图像算法集中在 image.py，Tab 仅负责参数组装与结果渲染，禁止在 UI 层实现阈值分割或形态学去噪。
- 配方 JSON 由 recipe.py 统一读写，新增字段时需保持向后兼容，避免破坏已有示教样本。
- PyInstaller 打包配置集中在 AurascopeV6.spec，静态资源（说明书.md、logo.*、CHANGELOG.md）通过 datas 清单声明而非运行时 import。
