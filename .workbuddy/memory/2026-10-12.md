# 2026-10-12

## 通读 Aurascope 项目代码

- 项目：Aurascope V4.3（by LINGYUE），PyQt6 + OpenCV 桌面视觉检测工具，面向微电子封装产线（金锡焊空洞率 / 测距 / 剪切力 / 物料计数 / 图像拼接 五个 Tab）。
- 架构：main.py 入口 → main_window.py 主窗口 + 4 个独立 Tab 模块；算法集中 image.py（detect_voids / detect_objects / detect_voids_local 系列），Canvas 层各 Tab 独立；导出用 pandas → CSV（utf-8-sig）。
- 已知问题记录在 handoff.md：detect_voids_local 双份实现未合并、main_window.py 内 edge_map 未初始化导致 Canny 验证静默失效、chk_roi_overlay 重复创建、canvas 缩放 Y 轴漂移、计数添加遗漏固定半径 8px 不可调。
- 工程约定：ui_components.py 的 create_* 只创建控件不加入布局；.py 必须 UTF-8。
