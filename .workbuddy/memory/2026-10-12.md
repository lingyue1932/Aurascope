## 修复：灰度相近的非焊料区被误学为焊料（2026-10-13）

- 用户报：与焊料灰度相近但非焊料的区域被学进去，金锡面积虚高。三层根因（设计文档 §13.11 详述）：
  1. **背景类被焊料灰度污染**（最隐蔽）：ROI 只画在焊层中段，焊层向左右延伸的同灰度像素落进周边环形带 → 背景类含焊料灰度 → 阈值被推到焊料之上 → 焊料漏检、更亮邻层反被当焊料。（合成复现：焊料 180/邻层 200 → 学出阈值 190）
  2. **闭运算桥接 1~3px 界面缝** → 焊层与邻层并成一个组件。改用横向结构元 (1×k) 只连左右碎片。
  3. **择带缺几何约束** → 新增几何先验择带（band_ref 匹配代价 = 中心偏移 + 面积/长宽比对数偏差，先限纵向窗口 ±25%）。
- 示教端提纯：焊层类从"中位数以上亮半边"改为**灰度主峰核** `_dominant_gray_core`（邻层比焊料亮时亮半边法会被污染）。
- 加固：阈值是绝对灰度、对亮度漂移脆弱（-8% 变暗即找不到带）→ 存 `ref_median` + 失败时按整体亮度补偿阈值重试。
- 新增自检：`bg_same_gray_frac`（周边与焊料同灰度像素占比），学习结果显示焊层亮度中位与 p5~p95 便于人工核对。
- 验证：专项 10/10（两个合成场景，修前虚高 2.04/1.33 倍，修后 ±5% 内）+ 回归 129 项；共 139 全绿，冒烟通过。

## 待实现方案：贴边空洞造成的边界缺口（2026-10-13 下午，用户要求先给方案）

- 现象（用户红标）：贴到焊层边界的空洞是暗的 → 不被当焊料 → 区域边界绕开它咬出缺口 → 缺口处面积被挖掉（分母偏小、空洞率偏大），局部形状失真。
- 机理：区域由"亮于阈值的连通域 + 填孔"定义，只有被亮像素完全包围的暗斑才会被填成孔；贴边的暗斑则变成边界缺口。
- 首选方案 A：把"贴边空洞"吸进区域再填孔——找贴边暗斑 → 判断像不像空洞（尺寸有界、形状类空洞、不与基板大区连通）→ 吸收+填孔 → 边界走暗斑外侧；暗斑仍作为区域内的孔被检出。
- 备选 B：只跨"暗缺口"的逐列包络一维闭运算（精细、实现繁）；C：大核形态学闭运算（最简单，但无差别桥接界面起伏，面积偏大）；D：以焊料为种子做区域生长（最贴物理、改动最大）。
- 待用户确认：红标处的暗结构是【空洞】还是【基板侵入/裂纹】——若是基板侵入，现在"边界跟着它走"反而是对的；另需原图量化缺口宽度/深度/灰度以定判据阈值。

## 最大空洞被面积上限排除（2026-10-13，用户追问 7.jpg/18.jpg）

- **现象**：7.jpg 检出 2 个/0.91%、18.jpg 检出 1 个/0.06%，最大最黑的空洞没标出。
- **定位**（用用户配方 `recipes/2.taught.json` 复现）：t_空洞=205 宽松、min_area 自动 12px² 都没问题，**卡在 `max_area=626px²`**——7.jpg 的 680px²（86×15，最暗 0）、18.jpg 的 812px²（80×16，最暗 0）全被上限切掉。18.jpg 的空洞率因此从真实 3.91% 少报成 0.06%（差 65 倍）。
- **根因同 §13.15**：上下限都从"点选尺寸"外推（max=2× 点选最大），用户点了小空洞 → 上限压低 → **最大的空洞反被排除**。
- **修复**：`max_area` 默认 None=自动（`max(400, 30%×带面积)`，仅作分割失败兜底）；schema_version→3，**加载旧配方自动迁移**上下限为自动档（旧值存 `*_taught`）；新增 `max_area_used`/`above_max_area_count`，界面显示"另有 N 个大暗斑未计入"，CSV 增两列，标注图显示"面积区间"。
- 实测：7.jpg 2个/0.91% → **3个/3.94%**；18.jpg 1个/0.06% → **2个/3.91%**；1.jpg/20.jpg 不变。回归 216 项全绿。对比图 `fix_bigvoid_7_18.png`。
- **教训（三次同类）**：面积上下限/阈值不能从"用户点选的样本"外推——样本少且偏，两端最该关注的反被切掉。判据锚定图像/带尺度；点选只用于定"长什么样"（灰度类），不定"多大算"；再用 below/above 计数与几何告警把可能漏检显式暴露。
