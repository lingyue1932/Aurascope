### 走查发现的 6 个真 bug（都已修 + 复验 ✔）
1. **QSpinBox / QComboBox 出现纯黑块** ✗
   根因：我用 CSS 三角（`border-left/right transparent + border-top 实色` ✗）画箭头 ✗
   —— **Qt QSS 不支持这个 hack** ✗ → 渲染成黑块 ✗
   修：数字框上下按钮 `width:0` 隐藏；下拉框改成"浅色端盖"（`::drop-down` 带左边框 + 圆角 ✗）
2. **剪切力页徽章 `x1.25`/`x2` 深底深字看不清** ✗
   根因：`f"color:{color}; background:{color}15;"` ✗ —— `{color}15` 是**网页写法** ✗
   Qt 当成 `#AARRGGBB`（alpha 在前 ✗）→ 变成深橄榄/深红底 ✗
   修：改成 `rgba(r,g,b,0.10)` + 1px 同色描边 ✔
3. **快速示教 / 学习报告：文字外层多出边框** ✗
   根因：`setStyleSheet("QFrame { … }")` ✗ + **QLabel 继承 QFrame** ✗ → 内部所有 QLabel 被套边框 ✗
   修：加 objectName 限定选择器（`QFrame#TeachLeftPanel` / `QFrame#LearnCard`）✔
4. **快速示教左栏提示文字右侧被截断** ✗ → 补 `setWordWrap(True)` + 左栏 210→232 ✔
5. **图片选择器缩略图全不显示** ✗（只有文件名）
   根因 1：`QImage`/`QPixmap` **没导入** ✗（NameError 被 `except: pass` 吃掉 ✗）
   根因 2：`it.setIcon(QPixmap)` ✗ —— **setIcon 要 QIcon** ✗ → 传 QPixmap 静默失败 ✗
   修：补导入 + `QIcon(self._loader(p))` ✔（ReportGo 的 `quick_teach.py` 同步修 ✔）
6. （附带）下拉框黑三角 —— 同 1 ✔

### 教训（写给以后的自己）
- **Qt QSS ≠ CSS** ✗：不支持 CSS 三角/变量/box-shadow；`setStyleSheet("QFrame{…}")` 会**波及所有 QLabel** ✗
- **`except: pass` 是 bug 放大器** ✗ —— 缩略图、图标两处都是被它吞掉的 ✗
- **UI 改动必须每个页面/弹窗都截图验** ✗ —— 前两轮只截主界面两个 tab ✗ 所以"改完还是很多 bug" ✗
- 走查脚本 `test_ui_audit.py` 已沉淀，后续改样式先跑它 ✔

## 「中间那条灰带是什么」→ 面板投影 + 分隔条（09:46 起）

用户截图指出批量页左面板右侧有一条**脏灰竖带** ✗

**根因（两层叠加）**
1. `teach_batch_tab._panel_frame()` 给面板加了
   `QGraphicsDropShadowEffect(blur=30, offset=(0,4), color=黑25)` ✗
   → 面板紧贴分隔条时，投影在浅底上就是一条**硬边灰带** ✗
2. `styles.py` 里 `QSplitter::handle:horizontal` 画了可见底色（`{border}` + margin）✗
   → 再叠上一条灰 ✗

**修**
- `_panel_frame` **去掉投影** ✔（扁平面板层次靠 1px 描边 + 底色差 ✔ 就够 ✗）
- 分隔条改**默认透明**（`QSplitter::handle { background: transparent }` ✗）
  + 只在 `:hover` 给 `border` 色、`:pressed` 给 `accent` 色作为拖动提示 ✔
- 实测 `tab1_示教_批量.png`：灰带消失 ✔ 只剩一道干净细缝 ✔

**回归**：App 276 项全绿 ✔ + 冒烟 ✔ + 9 张走查截图 ✔

### 教训
- **Qt 的 `QGraphicsDropShadowEffect` 不适合放在分隔器里的面板上** ✗
  会越过自身边界被裁切/与分隔条叠加成脏边 ✗ → 扁平风直接不用投影 ✔
- 分隔条默认要**不可见** ✗，只在交互时提示 ✔（否则永远是一条色带 ✗）
