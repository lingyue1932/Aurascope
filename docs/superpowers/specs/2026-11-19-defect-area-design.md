## 1. 背景与目标

工艺工程师需要对 SEM / X 光截面图中的裂纹、空洞等亮色或暗色结构做实际面积定量测量。v1.1 已实现单 ROI 显式检测、精确像素面积、标定、手动增删和 CSV。真实侧视图表明，一张图通常有多个相互独立的裂纹区域，需要分别设置阈值；逐缺陷面积文字会互相遮挡，必须从画布彻底删除。

本期目标流程：

```text
导入图片（只显示原图）→ 全图统一划线标定
→ 连续绘制多个矩形/多边形 ROI（自动编号、各自保存参数）
→ 点击“检测全部 ROI”→ 每框独立阈值检测与面积
→ 选择某框调参，仅重跑该框
→ 画布只显示 ROI 编号及该框总面积，不显示逐缺陷文字
→ 全部 ROI 总面积按有效缺陷像素并集去重 → 手动修正 → CSV 导出
```

非目标：不修改其他 6 个 Tab；不修改 `image.py` 既有函数；不做撤销栈、截图复制、后台线程、ROI 顶点/拖动变形、批量配方、CLAHE/形态学等增强检测。ROI 改形状采用删除重画。

### 3.1 ROI 数据项

每个 ROI 是独立字典（无需新建生产模块）：

```text
id: 稳定递增整数，删除单个 ROI 不重排；清空全部 ROI 或加载新图后重置为 1
roi: ('rect', (x,y,w,h)) 或 ('poly', [(x,y),...])
mask: 与 gray 同形的 uint8 0/255 区域
params: {'threshold': int, 'bright': bool, 'min_area': int}
objects: 当前框最终缺陷列表，对象含内部 roi_id
status: pending / active / error
manual_changed: bool
area_px: sum(object.area_px)，只用于本框面积，不用于跨框去重
```

Tab 持有 `rois`、`selected_roi_id`、标定、当前单框防抖 timer 和批量检测队列。`objects` 若保留为兼容属性，只能是按 ROI id 展开结果的只读视图，不再作为独立事实源。

### 3.2 组件边界

- Canvas 信号新增 ROI 点选；绘制完成仍只上报几何，不直接检测。
- Tab 向 Canvas 下发：多 ROI 及标签、当前 ROI id、展开对象、当前缺陷选择、汇总文本。
- 每个对象的 `mask` 始终为 bbox 局部数组；全图坐标只存于 `rect/cx/cy/points`。
- 总面积另用一张全图 uint8 并集 mask 计算，不能通过对象编号或 bbox 猜重叠。

## 4. 算法与数据流

### 4.1 单框检测与面积

继续使用：

```python
detect_defects(gray, threshold, bright, min_area, roi.mask)
```

面积是 `connectedComponentsWithStats(..., connectivity=8)` 的 `CC_STAT_AREA` 精确填充像素数；不使用 `contourArea`。单框面积：

```text
roi.area_px = Σ roi.objects.area_px
roi.area_real = roi.area_px × unit_per_px²
```

每次单框重跑整体替换该框 objects、缺陷重新编号并清空该框手动增删；其他 ROI 的对象、编号、参数、手动修正均不变。

### 4.2 全部 ROI 去重面积

每次检测、手动增删、删除 ROI 后重建或增量更新并集：

1. 创建与 gray 同形的零 mask。
2. 对每个 ROI 的每个保留对象，把其 bbox 局部 `obj['mask'] != 0` OR 到全图对应 bbox。
3. `union_area_px = cv2.countNonZero(union_mask)`。
4. `union_area_real = union_area_px × unit_per_px²`。

因此每框可有不同阈值，手动对象也参与；孔洞不会被填入。例：两框各 200px²，共同有效像素 50px²，则每框均显示 200px²，全部 ROI 总面积为 350px²。全局不再显示可能被重复计算的“缺陷总数”，主汇总只显示去重面积及 ROI 数量。

### 4.3 标定与格式化

沿用 v1.1：`unit_per_px = 实际长度 / 标定线像素长度`；五单位线性因子不变；显示 `fmt_area()` 双向调档，0 不降档；CSV 固定标定单位、`%.6g`。未标定显示整数 px²，CSV 实际面积留空、单位写“未标定”。标定变化不重跑检测、不清手动修正。

### 4.4 显式检测编排

- 导入、选择 ROI、删除 ROI、未激活 ROI 的调参/Otsu 均不调用 `detect_defects`；画完 ROI 立即自动检测该框，不影响其他框。
- “检测全部 ROI”是整批重跑：清空所有框旧结果和手动增删，以各框当前参数检测全部。无 ROI 时拒绝，不默认全图。全部已检测时按钮为“停止并清空”。
- 批量按 ROI 排队，一次事件循环只处理一个框；首框可立即执行，其余由 0ms singleShot 调度。状态显示 `正在检测 i/N`；停止时取消未执行项并清空所有结果。
- 某框已有结果后，修改其阈值、亮/暗或最小面积，仅启动该框 150ms 防抖；Otsu 只计算当前框，若已激活则重跑当前框。
- 防抖尚未执行就切换选择、新增或删除 ROI 时，停止旧 timer；旧框转为 pending 并清除与新参数不匹配的旧结果，选择本身不触发检测，也不允许导出过期结果。
- 新增 ROI 画完即自动检测该框（状态 active）；再次点击“检测全部 ROI”才整批重跑。检测循环每 10 个连通域让出事件循环，避免长检测和阈值拖动卡 UI。
- 删除 ROI 只删除该框结果并更新并集；清空全部、停止、新图才清空所有。
- 单框算法异常把该框标为 error、保留其他框结果并继续批量；状态表给错误提示。参数输入由控件保证合法。

### 4.5 手动增删

- 必须选择已激活 ROI；使用当前框 bright 和局部 Otsu。
- 添加点击必须落在当前 ROI mask 内，否则拒绝。仍取 40px 半径窗口、当前 ROI 内局部 Otsu、真实 mask 命中、20px 最近质心回退、当前框内重叠拒绝、双击确认/ESC 取消；候选 mask 同时按当前 ROI 裁剪，框外像素不得计入。
- 删除只搜索当前 ROI objects，真实 mask 命中或 2px 容差；重叠 ROI 的另一框不受影响。
- 当前框重跑才清该框手动增删；整批重跑清全部。缺陷 id 在框内不重排。

## 5. 交互与显示

### 5.1 ROI 绘制与选择

- 工具：划线标定、矩形框选、多边形框选、添加遗漏、删除误检；右键平移、滚轮缩放常驻。再次点击当前工具或按 ESC 退出工具并返回 ROI 点选模式。
- 矩形边长 >5px；多边形至少 3 点且面积非零。每次有效完成追加 ROI 并自动选中新框。
- 新框复制绘制前所选 ROI 的三个参数；无旧框时使用侧栏当前默认值。
- ROI 默认蓝色虚线，当前框加粗/黄色高亮；无填充。
- 非绘制模式下点击 ROI 内部或轮廓选择该框；重叠时后绘制者优先。ROI 表选择同步画布和参数控件。
- 按钮：“删除当前 ROI”“清空全部 ROI”。删除单个 ROI 时其余编号稳定；清空全部 ROI 或加载新图后从 1 重新编号。

### 5.2 画布结果

- 所有已检测对象继续显示绿色半透明真实 mask 和绿色轮廓；明细选择可黄色高亮，删除悬停红色。
- 每个 ROI 仅一个屏幕空间标签：未运行 `ROI n 待检测`，运行后 `ROI n {fmt_area}`，失败 `ROI n 检测失败`。
- **彻底删除逐缺陷面积/编号文字、`chk_show_labels` 开关和对象 labels 渲染循环。任何对象数量、表格选择或缩放都不得恢复。**
- 右上角汇总：`全部 ROI 总面积（重叠去重）: {area} · {ROI数} 个区域`，未标定追加提示。
- 标定线和长度标签保留；`_text` 只服务 ROI、标定等少量标签。

### 5.3 侧栏

- “检测区域”：矩形/多边形、删除当前、清空全部。
- “阈值检测”：当前 ROI 标题、`检测全部 ROI / 停止并清空`、阈值、Otsu、亮/暗、最小面积。
- “测量结果”：去重总面积、ROI 汇总表、当前框缺陷明细、CSV。
- ROI 表列：ROI、状态、阈值、亮/暗、最小面积、缺陷数、总面积。选行使控件静默同步，避免触发检测。
- 缺陷明细列：编号、像素面积、实际面积、来源，只展示当前 ROI；单缺陷面积仍可从表格和 CSV 读取。

### 5.4 CSV

```text
ROI编号,缺陷编号,像素面积,实际面积,面积单位,质心x_px,质心y_px,来源
```

按 ROI id、缺陷 id 排序，所有 ROI 写入同一个明细 CSV，不混入总计行。无对象不产出文件；批量检测进行中拒绝导出部分结果；写临时文件后 `os.replace`，失败保留旧目标文件。

## 6. 错误与边界

| 场景 | 行为 |
|------|------|
| 无图/无 ROI 检测 | 提示并拒绝，无算法调用 |
| 空结果 | 当前框面积 0、明细空，其他框和界面正常 |
| 重复标定 | 全图统一覆盖，只重算显示 |
| ROI 重叠 | 每框独立；总计按最终有效像素并集去重 |
| 新框复制参数 | 复制绘制前选择项；复制值而非共享可变状态 |
| 批量期间停止/新图 | 停止 timer、使队列失效，不提交过期结果 |
| 单框失败 | error 状态，不中止其他 ROI，不崩溃 |
| 手动添加在 ROI 外 | 拒绝并提示选择/点击当前区域 |
| 大图/密集缺陷 | 导入不检测；批量逐框让出事件循环；无逐缺陷文本；单框同步算法仍可能耗时 |
| 损坏图片/TIF | 保留旧图和全部 ROI/结果，显示加载错误 |

## 7. 关键决策

| # | 决策 | 理由 |
|---|------|------|
| D1 | 独立 ROI 任务，不合并成一张跨框阈值图 | 防止跨框连通域合并，保证独立调参和结果归属 |
| D2 | 一次检测全部；激活后只重跑当前 | 减少逐框启动操作，同时避免无关区域重算 |
| D3 | 允许重叠，总计按最终 mask 并集去重 | 保留框选自由，避免重复面积 |
| D4 | 三参数独立，新框复制当前 | 相似区域连续框选效率高，各框后续互不影响 |
| D5 | 删除所有逐缺陷画布文字及开关 | 即使少量文字也可能重叠；表格/CSV 已完整保留数据 |
| D6 | 编号稳定，删除不重排 | 画面、表格和 CSV 可追溯 |
| D7 | 批量排队但单框同步，不引线程 | 改善多框响应，控制并发复杂度；单大框耗时作为已知限制 |
| D8 | 手动修正归属当前 ROI 且限框内 | 防止结果无法归属和无意修改其他区域 |

### 8.2 人工验收

- 同一侧视图框选上方和右侧裂纹区，分别 Otsu/调阈值，两框掩膜与面积符合视觉。
- 故意让两个 ROI 部分重叠，对照每框面积与去重总面积。
- 任意缩放、选择缺陷、切换 ROI，均不出现逐缺陷面积文字。
- 有比例尺原图与 ImageJ 同阈值对照误差 ≤1%；Excel 打开 CSV 无乱码。
- 旧示教回归仍需用户补齐参考配方后复跑；数据缺失不通过代码兜底掩盖。
